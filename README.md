# House Prices: Advanced Regression Techniques

Решение регрессионного соревнования Kaggle House Prices. Метрика соревнования: RMSE между логарифмом предсказания и
логарифмом реальной цены, поэтому все модели обучаются на `log1p(SalePrice)`, а в сабмит уходит `expm1` предсказания.

Итоговый лучший результат: **усреднение пяти моделей (Lasso, XGBoost, LightGBM, CatBoost и нейросеть), RMSE 0.1087 на
кросс-валидации и 0.1234 на публичном лидерборде**.

## Структура репозитория

Исследование разбито на ноутбуки по темам. Общий код (предобработка, валидация, модели) вынесен в модули, которые
использует `main.py` и ноутбуки `classical_models`, `optuna_tuning`, `dnn` и `ensembles`. Ноутбуки
`baseline_and_preprocessing` и `feature_engineering` модули не импортируют, в них принятая предобработка собирается
шаг за шагом и проверяется по гипотезам, модуль `src/preprocessing.py` воспроизводит её итоговый результат.

**Ноутбуки в порядке исследования:**
- `notebooks/eda_and_hypotheses.ipynb` - разведочный анализ, распределения, пропуски, выбросы, таблица гипотез
- `notebooks/baseline_and_preprocessing.ipynb` - схема валидации, бейзлайн, проверка гипотез по предобработке, в том числе эксперимент с кодированием категорий
- `notebooks/feature_engineering.ipynb` - новые признаки, проверка гипотез по feature engineering
- `notebooks/classical_models.ipynb` - линейные модели, KNN, дерево, случайный лес и три бустинга с широким подбором гиперпараметров через GridSearchCV и RandomizedSearchCV
- `notebooks/optuna_tuning.ipynb` - подбор гиперпараметров тех же моделей через Optuna и сравнение с прошлым ноутбуком, вне чеклиста
- `notebooks/dnn.ipynb` - PyTorch MLP: число слоёв, BatchNorm, Dropout, размеры слоёв, активации, оптимизаторы, scheduler, параметры обучения, Embedding для категориальных признаков
- `notebooks/ensembles.ipynb` - усреднение, voting и stacking, эксперимент без нейросети, результаты на лидерборде

**Расположение файлов.** В корне лежат только `README.md`, `config.yaml`, `main.py`, `requirements.txt` и `.gitignore`, ноутбуки лежат в `notebooks`, код в `src`, данные и сабмиты не хранятся в репозитории, это папки `data` и `submissions`.

**Модули с общим кодом в папке `src`:**
- `src/preprocessing.py` - принятая в ноутбуках предобработка признаков и загрузка данных, `build_preprocessor` для one-hot и масштабирования
- `src/validation.py` - RMSE на логарифме цены, кросс-валидация по KFold и обучение на всём трейне для сабмита
- `src/dnn.py` - `NeuralNetRegressor`, нейросеть на PyTorch с интерфейсом sklearn, чтобы её можно было ставить в `Pipeline` и в ансамбли
- `src/models.py` - фабрика моделей и ансамблей, собирает любую модель по имени из `config.yaml`

**Пайплайн для воспроизведения:**
- `config.yaml` - гиперпараметры всех моделей, описание ансамблей и выбор модели для запуска
- `main.py` - загружает данные, считает кросс-валидацию выбранной модели и сохраняет сабмит
- `src/run_notebooks.py` - выполняет все ноутбуки по очереди, чтобы проверить, что всё воспроизводится с нуля

## Установка

```
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

Проект использует только CPU. Если `pip install` подтянет тяжёлую версию PyTorch с CUDA, поставьте её отдельно с CPU-индекса:
```
pip install torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu
```

Данные соревнования не лежат в репозитории, скачать их можно через Kaggle CLI, версия CLI из `requirements.txt` только
скачивает архив и не распаковывает его:
```
kaggle competitions download -c house-prices-advanced-regression-techniques -p data
unzip data/house-prices-advanced-regression-techniques.zip -d data
```
Если `unzip` недоступен, например в cmd или PowerShell на Windows, архив можно распаковать средствами Python:
```
python -m zipfile -e data/house-prices-advanced-regression-techniques.zip data
```
Или вручную со [страницы соревнования](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)
в `data/train.csv` и `data/test.csv`.

## Запуск

```
python main.py
```

Прогонит модель из `config.yaml` через 5-fold кросс-валидацию, напечатает RMSE на логарифме цены и сохранит сабмит в
`submissions/<имя_модели>_submission.csv`. По умолчанию это усреднение пяти моделей, лучший результат проекта.

Чтобы запустить другую модель или ансамбль, поменяйте поле `model` в `config.yaml` на ключ из секции `models`
(`lasso`, `ridge`, `elasticnet`, `random_forest`, `xgboost`, `lightgbm`, `catboost`, `dnn`) или `ensembles`
(`averaging_5_models`, `averaging_4_models`, `stacking_ridge_5_models`, `stacking_ridge_4_models`). Гиперпараметры
меняются там же, `main.py` их не подбирает, а использует значения, найденные в ноутбуках.

Свой файл конфига: `python main.py --config my_config.yaml`.

Чтобы прогнать по кросс-валидации все модели и ансамбли и увидеть сравнительную таблицу без сабмита, поставьте
`model: all`.

Чтобы воспроизвести все эксперименты с нуля, а не только финальный пайплайн:

```
python src/run_notebooks.py
```

Локально заняло 2.5+ часа, из них основное время уходит на подбор гиперпараметров в `classical_models.ipynb` и
`optuna_tuning.ipynb`.

## Результаты

RMSE на логарифме цены. Кросс-валидация: KFold с 5 фолдами и `random_state=42`. Лидерборд: публичная оценка после
загрузки сабмита, обученного на всём трейне. Таблица по возрастанию оценки на лидерборде:

| Модель | CV RMSE | Лидерборд |
|---|---|---|
| **averaging_5_models** | **0.1087** | **0.1234** |
| stacking_ridge_4_models | 0.1084 | 0.1242 |
| dnn | 0.1136 | 0.1263 |
| lightgbm | 0.1136 | 0.1273 |
| lasso | 0.1112 | 0.1276 |
| xgboost | 0.1149 | 0.1282 |
| catboost | 0.1162 | 0.1288 |

Случайный лес на кросс-валидации дал 0.1315, в сабмиты не попал. Гиперпараметры моделей подбирались на трейне, а нейросети
по этим же фолдам, поэтому оценки на кросс-валидации немного оптимистичны, лидерборд у всех семи моделей хуже на 0.013
до 0.016.

**Выводы по проекту:**
- регуляризованные линейные модели, Lasso, Ridge и ElasticNet, на этом датасете сильнее бустингов, а разница между обычной линейной регрессией и Ridge, 0.1198 и 0.1117, больше, чем между Ridge и лучшим бустингом классического ноутбука, CatBoost с 0.1165
- неглубокие деревья устойчиво выигрывают в бустингах, у XGBoost, CatBoost и LightGBM лучшая глубина от 2 до 4
- Optuna с непрерывными диапазонами гиперпараметров заметно улучшила бустинги, LightGBM с 0.1199 до 0.1150, а на линейных моделях разницы почти нет
- нейросеть с одним скрытым слоем, ELU, Dropout 0.3 и SGD дошла до уровня бустингов, а число слоёв, BatchNorm, scheduler и Embedding для категориальных признаков не дали улучшения
- любой ансамбль лучше любой одиночной модели, а выбор схемы, усреднение, voting или stacking, почти не влияет на качество
- порядок одиночных моделей на кросс-валидации не воспроизвёлся на лидерборде, Lasso с лучшим результатом на кросс-валидации оказалась пятой из семи, а вот преимущество ансамблей сохранилось
